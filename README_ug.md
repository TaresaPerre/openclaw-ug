 > بىر ئېچىلىپلا ئىشلەتكىلى بولىدىغان ئۇيغۇرچە  AI  كونترول مەركىزى.  يۇقىرى ئىقتىدارلىق GPU كەتمەيدۇ، [OpenClaw] (https://github.com/openclaw/openclaw )نى ئاساس قىلىپ قۇرۇلغان،ساپ ئۇيغۇرچە سۆز مۇدىرىنى ئىشلىتىشكە تەمىنلەيدۇ. 

 ئۆزۈمنى تونۇشتۇرۇپ ئۆتەي، مەن بىر ئۇيغۇر تېخنىكا ھەۋەسكارى،  ھازىرغىچە كومپيۇتېر ساھەسىدە تېخى ئۇيغۇرچە AI  مەھسۇلات يوقلىقىنى بايقىدىم. [OpenClaw] بۇ قۇرۇلمىنى مەن خېلى ئۇزاق ئىشلەتتىم، ھەقىقەتەن ياخشى ئىكەن، شۇڭا بىر ساپ ئۇيغۇرچە [OpenClaw] دېتالنى ياساش نىيىتىگە كەلدىم، ئۇيغۇر خەلقىمىزمۇ AI نىڭ قولايلىقىدىن بەھرىمان بولالايدۇ.  ئەگەر چۈشۈرۈپ ئىشلەتمەكچى بولسىڭىز ،ئىلخەت بىلەن ئالاقىلاشسىڭىز بولىدۇ.  ئالاقىلىشىش ئادرېسى:[ Taresa_Perre@outlook.com ] (mailto:Taresa_Perre@outlook.com)


## خەۋەر
بىر مەزگەل سىناش ۋە ئىنكاستىن كېيىن، openclaw ئۇيغۇرچە نۇسخىسى ھازىر ناھايتى مۇقىم ۋە ئىشەنچىلىك! كود [Release](https://github.com/TaresaPerre/openclaw-ug/releases/) دە ئېلان قىلىندى، چۈشۈرۈپ ئورنىتىڭىز. قىسقۇرۇلغان فلودېرنى ئېچىپ بولغاندىن كېيىن، تۆۋەندىكى بۇيرۇق بىلەن بىر چېكىش ئارقىلىق قاچىلاش:
```powershell
powershell -ExecutionPolicy Bypass -File openclaw-install.ps1
```
تېخىمۇ كۆپ قاچىلاش باسقۇچلىرى ئۈچۈن، OpenClaw Installation Guide_ug.pdf نى كۆرۈڭ.

## چۈشەندۈرۈش:

 بىز باشتا كىچىك دائىرىدە ئابونىتلارنىڭ ئىنكاسىنى قوبۇل قىلىپ،  تۈزىتىلگەندىن كېيىن كەڭ كۆلەمدە چۈشۈرۈش ئادرېسىنى يوللايمىز.  كۆپچىلىكنىڭ ئاكتىپلىق بىلەن ئىشلىتىشنى قارشى ئالىمىز .

  OpenClaw دېگەن نېمە؟ 

 OpenClaw  دېگەن كۈچلۈك تورسىز  AI ، مۇلازىمەت رامكىسى، مۇرەككەپ قورال تەرتىپلەش ۋە خىزمەت جەريان توپلىمىنى قوللايدۇ، بۇ دېتال شۇنىڭ ئۈچۈن ياخشىلانغان،  ئەڭ مۇھىمى ئۇيغۇرچىنى  قوللايدۇ،يەرلىك چوڭقۇر ياخشىلانغان،تولۇق UI يەرلىكلەشتۇرۇلگەن، چوڭقۇر ياخشىلانغانئىشارەت سۆز قۇرۇلۇشى. بۇ ئادەتتىكى تەرجىمە ئەمەس .

## ئالاھىدىلىكى: 

 OpenClaw  تولۇق ئىقتىدارى: يەرلىك ھۆججەتلەرنى زىيارەت قىلىش، API ،Telegram كىرىشتۇرۇلگەن .

 شەخسى مەخپىيەتنى قوغداش: پۈتۈنلەي تورسىز ئىشلىنىدۇ.  سانلىق مەلۇماتلار سىزنىڭ كومپيۇتېرىڭىزدىن ھەرگىز ئايرىلمايدۇ ،ئادەتتىكى خىزمەت ئۈسكۈنىدە نورمال ئىشلىنىدۇ.

مەشغۇلات سىستېمىسى: Windows10/11(64  بېيىتلىك سىستېما )  ،ئىچكى ساقلاشبوشلۇقى GB≤4، ساقلاش بوشلۇقىGB≤10 دىن ئارتۇق.  LLM API نىڭ تەلىپىنى سۇنۇش ئۈچۈن تورغا ئۇلاش كېرەك.  ئاز كۈندىن كېيىن  macOS  بىلەن  Linux  نۇسخىسى چىقىرىلىدۇ.

 
 ##  تېز سۈرەتتە ئىشلىتىش ،كودلاش لازىم ئەمەس. 


 بىرىنچى قەدەم :چۈشۈرۈپ  ئاچقاندىن  كېيىن ھۆججەتنى يەرلىككە ساقلاش كېرەك،  دىققەت :ھۆججەت ساقلاش يولىدا بوشلۇق ئورۇن بەلگىسى بولسا بولمايدۇ.مەسىلەن D:\openclaw\ توغرا، D:\My Folder\Open Claw\ بولسا بولمايدۇ .

ئىككىنچى قەدەم :جىيا قىلغاندىن كېيىن، ھۆججەت ئىچىدە  PowerShell  ھۆججەتنى بېسىپ ئاچىمىز :

```powershellpowershell -ExecutionPolicy Bypass -File openclaw-install.psl````Bypass` 

بۇ پەقەت قاچىلاشنىڭ ئۆلچەملىك جەريانى،ئىنتايىن بىخەتەر .

 ئۈچىنچى قەدەم :سەپلانما ۋە  Web ئېچىلىش رامكىسىhttp//127.0.0.1:18789/chat``دا ئاپتوماتىك ئېچىلىدۇ.

 1.ئاچقۇچنى ئېلىش.  [NVIDIA NIM ](https://build.nvidia.com/settings/api-key )  تور بېتىدە ھەقسىز نومۇرنى يىغىپ ئالماشتۇرۇڭ.

 2.ئاچقۇچنى كىرگۈزۈش.  ئاچقۇچنى سەپلەنمە رامكىسىغا چاپلاش كېرەك. 

 3.سۆزلىشىش.  ئۇيغۇرچە ھالىتى ئۆزلۈكىدىن قوزغىلىدۇ،يەرلىك مودېل بولسا شۇ مودىلغا ماس كېلىدىغان   vLLM، Ollama مودېلنى تاللاڭ.url  سىزنىڭ يەرلىك ئۇلىنىش ئېغىزنىڭ نومۇرى،   api key  نى بىر sk-anyگە   يېزىڭ.

 يەرلىك مودېلنى تاللىغىلى بولىدۇ، ئەگەر ئۈسكۈنىڭىزدە يەرلىك مودېل بار بولسا، مودېل تەمىنلىگۈچى تاللىشىدا  شۇنىڭغا ماس كېلىدىغان قۇرۇلمىنى تاللاپ ،ئۇچۇرنى كىرگۈزۈڭ.  مەسىلەن ئىشلەتكەن vLLM رامكىسىنى ئاساس قىلغان  مودېل: vLLM -<  نى  تاللاپ،  url رامكىسىدا يەرلىك مۇلازىمەت ئادرېسىنى كىرگۈزۈڭ،(مەسىلەن`http://127.0.0.1:8000/v1` )،  API Key گە خالىغان ئورۇن بەلگىسى كىرگۈزۈڭ ( مەسىلەن`sk-any` )،قالغان مەزمۇننى ئەۋەتىلگەن <OpenClaw ئىشىلتىش دەرىسلىكى.pdf >  دىن كۆرۈڭ.  بۇ دېتالنى ئىختىيارى ئىشلەتسىڭىز،ئۆزگەرتسىڭىز، ياكى باشقىلارغا ئەۋەتسىڭىز بولىدۇ.
